# 🌦️ Projet : Analyse de données météorologiques (NumPy)

Ce projet a été réalisé dans le cadre de ma formation en Intelligence Artificielle au Collège CDI.

L’objectif :
Analyser et manipuler un jeu de données météorologiques en utilisant exclusivement NumPy.

## 🎯 Compétences développées
- Manipulation de matrices NumPy
- Calcul de moyennes, maxima, minima
- Nettoyage de données
- Analyse statistique simple
- Visualisation basique (optionnelle)

## 💡 Contenu du projet
- Chargement des données météorologiques
- Conversion en tableau NumPy
- Calcul de :
  - Température moyenne
  - Température maximale
  - Température minimale
  - Variation journalière
- Détection de outliers

## 📁 Fichiers
- `projet-meteo-numpy.ipynb` — Notebook complet du projet
- `data_meteo.csv` — Jeu de données utilisé

## 🚀 Résultats
Le projet démontre la compréhension des opérations fondamentales NumPy appliquées à un contexte réel : l’analyse de données météo.
