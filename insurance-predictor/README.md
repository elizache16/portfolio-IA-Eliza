🧠 InsurancePredictor — Modèle de Régression (Python & Programmation Orientée Objet)

Projet réalisé dans le cadre de ma formation en Intelligence Artificielle au Collège CDI.
L’objectif du projet est de construire un pipeline complet de régression en utilisant une architecture en Programmation Orientée Objet (OOP) afin de prédire les coûts médicaux d’assurance.

🎯 Objectif du projet

Développer un modèle de régression structuré, robuste et réutilisable capable de prédire les coûts d’assurance santé à partir de variables telles que :

âge

IMC

tabagisme

région

nombre d’enfants

Le projet démontre ma capacité à concevoir un pipeline professionnel incluant exploration, nettoyage, entraînement des modèles et évaluation.

🧰 Compétences développées
🔹 Data Science & Machine Learning

Manipulation et analyse de données avec Pandas

Visualisation (Matplotlib, Seaborn)

Prétraitement : encodage, normalisation, nettoyage

Régression Linéaire & Régression Ridge

Train/Test split, validation simple

Mesures d’évaluation : MAE, RMSE, R²

🔹 Programmation & Architecture

Programmation Orientée Objet (classes, attributs, méthodes)

Organisation d’un pipeline ML modulaire

Lecture, encapsulation et documentation du code

Création d’une classe principale : InsurancePredictor

📊 Résultats

Le modèle construit offre :

une prédiction stable et cohérente des coûts médicaux,

une bonne capacité explicative grâce à la régression linéaire,

une réduction du surapprentissage avec Ridge Regression.

Ce projet démontre ma capacité à structurer un pipeline ML complet et professionnel en Python.
