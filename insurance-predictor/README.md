# 🩺 InsurancePredictor – Régression (Python OOP)

Ce projet a été réalisé dans le cadre de ma formation en Intelligence Artificielle au Collège CDI.

## 🎯 Objectif
Construire un modèle de régression permettant de prédire les coûts médicaux d’assurance en utilisant Python et une architecture orientée objet (OOP).

## 🧩 Compétences développées
- Programmation orientée objet (classes, méthodes)
- Manipulation de données avec Pandas
- Prétraitement : nettoyage, encodage, normalisation
- Régression linéaire & Régression Ridge
- Split Train/Test
- Évaluation du modèle (MAE, RMSE, R²)
- Visualisation des résultats

## 📂 Structure du projet
- `insurance_predictor.py` — Script principal avec la classe InsurancePredictor
- `model_training.ipynb` — Notebook complet du projet
- `insurance.csv` — Jeu de données utilisé

## 📊 Résultats
Le modèle prédit les coûts médicaux avec une performance stable.  
Ce projet démontre l’utilisation de classes Python pour structurer un pipeline de régression.
